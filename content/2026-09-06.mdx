### 5. You probably don't need two routers — do this instead

For better coverage or more wired connections, mesh, access points and Ethernet switches usually make more sense than a second active router.


:::brief

Engadget explains that adding a second router in normal mode creates double NAT, which can disrupt online gaming, port forwarding, and device discovery. Instead, the article recommends using a mesh Wi-Fi system or configuring an existing router in access point mode to extend the same network cleanly.

- Double NAT occurs when two routers each perform their own Network Address Translation.
- Mesh systems let nodes cooperate under a single network rather than creating independent routed networks.
- Access point mode disables features like firewall and IP sharing on the secondary router.

:::

### 9. What's the difference between volatile and non-volatile memory?

Volatile and non-volatile memory are both vital parts of modern computers and devices, but how do they work together?


:::brief

Engadget explains the difference between volatile and non-volatile memory, clarifying that volatility refers only to whether data survives a power loss and does not determine speed or capacity. DRAM requires continuous refresh cycles while SRAM retains state without them as long as power is supplied.

- DDR5 is a current form of DRAM in computers; LPDDR5X is common in mobile devices.
- AMD Ryzen AI Max chips support up to 128 GB of unified memory.
- The Ryzen 9 9950X3D includes 144 MB of combined L2 and L3 SRAM cache.
